## Требования к мобильной версии приложения  

### Общее положение  
Отдельно требования к мобильной версии продукта не создавались: они идентичны требованиям к веб-версии, за исключением следующих дополнений и изменений.

### Дополнения для мобильной версии  

#### 1. Кэширование результатов  
Приложение должно кэшировать результаты успешной конвертации дат для оптимизации/сокращения трафика и энергопотребления.

**Алгоритм работы:**
1. При вводе даты сначала проверяется наличие результата в кэше
2. Если дата найдена в кэше — результат отображается без выполнения API-запроса
3. Если дата не найдена в кэше — выполняется API-запрос к серверу
4. После успешного получения ответа результат сохраняется в кэш

#### 2. Размер кэша  
В кэше сохраняются последние 7 (семь) уникальных результатов конвертации.

**Правила:**
- Кэш работает по принципу LRU (Least Recently Used)
- При превышении лимита удаляется самый старый результат
- При повторном обращении к дате её позиция в кэше обновляется

#### 3. Поведение при отсутствии интернета  
- Если запрашиваемая дата есть в кэше — результат отображается
- Если запрашиваемой даты нет в кэше — отображается ошибка: `"Нет соединения с интернетом"`

#### 4. Интерфейсные изменения  
В мобильной версии не отображается информация об источнике данных (из кэша или из API). Это внутренняя оптимизация.

### Исключённые требования веб-версии  
Следующие требования веб-версии не актуальны для мобильной версии:
- Tab-навигация между частями даты (отсутствует физическая клавиатура)
- Использование клавиши Enter (отсутствует физическая клавиатура)
- Hover-эффекты (отсутствует курсор мыши на тач-экране)
- Указатель курсора (`pointer`, `not-allowed`)
- Фиксированные разрешения экрана для десктопа (1920x1080, 1600x900)
