## Требования
 
### Поле ввода

Одно поле с маской `__.__.____` 

В поле плейсхолдер: `ДД.ММ.ГГГГ`

В поле (справа) есть кнопка `Х`, позволяющая очистить поле.
При наведении курсора на кнопку очистки поля возникает hover-эффект - меняется фон кнопки. При наведении курсора на кнопку `Х` указатель должен меняться на `pointer`. 

**Допустимые символы:**  
Только цифры. Точки при вводе даты проставляются автоматически.

Не должно быть значения `"00"` для дня и месяца и `"0000"` - для года. 
Допустимый диапазон значений: 
- день: 01 - 31
- месяц: 01 - 12
- год: 1900 - 2100

**Учесть диапазон значений для дней:**
- для января, марта, мая, июля, августа, октября, декабря: 01 - 31
- для апреля, июня, сентября, ноября: 01 - 30
- для февраля високосного года: 01 - 29
- для февраля НЕвисокосного года: 01- 28
- для февраля 1900 и 2100 годов: 01 - 28
- для февраля 2000 года: 01 - 29

Крайние даты для года: 
- 01.01.1900 
- 31.12.2100 

Кнопка **"Конвертировать"**.  
При наведении указателя на кнопку `"Конвертировать"` возникает hover-эффект - кнопка приподнимается. При наведении курсора на кнопку `"Конвертировать"` указатель должен меняться на `pointer`. 
Если кнопка НЕактивна, то при наведении курсора указатель должен меняться на `not-allowed`.
Кнопка `"Конвертировать"` неактивна, если дата не введена полностью.

После нажатия (при корректно введённой дате) отображается область вывода результата, в которой, свою очередь, отображаются: 
- день недели, соответствующий дате (`дата → день недели`)
- кнопка `"Теперь следующая дата?"` 

При этом кнопка `"Конвертировать"` исчезает.

При наведении куросора на кнопку `"Теперь следующая дата?"` возникает hover-эффект - менятся фон. Также при наведении курсора на кнопку указатель должен меняться на `pointer`. 

После нажатия на кнопку `"Теперь следующая дата?"` результат сбрасывается: поле ввода очищается, а `"дата → день недели"` - исчезает. То есть в итоге отображается начальный экран с активным полем ввода.

Если введены невалидные значения - отображается валидационное сообщение (красным цветом) об ошибке - `"Некорректная дата......".`

Полный текст ошибки: 

```
Некорректная дата

Проверьте, что дата в допустимом диапазоне
Учтите, что:
в январе, марте, мае, июле, августе, октябре, декабре — 31 день
в апреле, июне, сентябре, ноябре — 30 дней
в феврале високосного года — 29 дней
в феврале невисокосного года — 28 дней
в феврале 1900 и 2100 годов — 28 дней
в феврале 2000 года — 29 дней
```

Дни недели:
- понедельник
- вторник
- среда
- четверг
- пятница
- суббота
- воскресенье


При обновлении страницы данные не сохраняются.

Кнопка (переключатель) `"Тёмная тема / Светлая тема"` в правом верхнем углу.
При наведении курсора на кнопку смены темы возникает hover-эффект - меняется фон кнопки. Кнопка смены темы меняется в зависимости от выбранной темы. При наведении курсора на кнопку смены темы указатель должен меняться на `pointer`.

Между кнопками и полем можно переключаться кнопкой `"Tab"`. Кнопки при этом можно нажать клавишей `Enter`. То есть конвертером можно пользоваться, используя ТОЛЬКО клавиатуру (`Tab` + `Enter` + сочетания клавиш для поля ввода).

**ВАЖНО:** можно просто ввести дату и нажать `Enter` - произойдёт конвертация. 

Данные в поле можно: 
- копировать (в т.ч. частично), 
- вставить (в т.ч. частично), 
- редактировать (в т.ч. частично), 
- удалять (в т.ч. частично)

При потере соединения с интернетом отображается валидационное сообщение `Ошибка соединения с сервером`. 
Дата, введённая в поле, при этом остаётся.
